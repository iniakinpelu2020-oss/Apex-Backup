Apex Backup

What will be included

Every key in this browser's localStorage that starts with apex.. Nothing is uploaded — the file is built and saved on this device.

    No Apex data found in this browser yet. Open an app and save something first.

    Restore

    Restoring writes straight into localStorage. Existing keys with the same name are replaced, so export first if you are not sure.

    Scope

    This covers localStorage only. Photos and files held in IndexedDB (Apex Camera, Apex Gallery) are not included, and nothing from another browser profile is reachable from here.
